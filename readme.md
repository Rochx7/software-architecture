# 📚 Software Architecture Studies

Este repositório foi criado com o objetivo de documentar minha jornada de aprendizado em **Arquitetura de Software**, **Qualidade de Código**, **Testes Automatizados** e **Boas Práticas de Desenvolvimento**.

Aqui reúno anotações, resumos, exemplos práticos, diagramas, exercícios e implementações desenvolvidas durante meus estudos. O foco principal é consolidar conhecimento por meio da escrita e da aplicação prática dos conceitos estudados.

---

## 🎯 Objetivos

- Aprender fundamentos sólidos de Arquitetura de Software.
- Compreender os principais padrões arquiteturais utilizados no mercado.
- Melhorar a capacidade de projetar sistemas escaláveis e de fácil manutenção.
- Aprimorar conhecimentos sobre testes automatizados.
- Desenvolver habilidades de refatoração e evolução de código legado.
- Aplicar princípios de Clean Code, SOLID e Domain-Driven Design (DDD).
- Construir uma base sólida para atuar como Software Engineer e Software Architect.

---

# 🏛️ Arquitetura de Software

Estudo sobre um dos padrões arquiteturais mais importantes para desacoplamento de regras de negócio e infraestrutura.

### Tópicos estudados

- Fundamentos da Arquitetura Hexagonal
- Ports and Adapters
- Drivers e Driven Adapters
- Core da Aplicação
- Ports (Portas)
- Adapters (Adaptadores)
- Inversão de Dependência (DIP)
- Casos de Uso
- Domínio
- Testabilidade
- Separação de Responsabilidades
- Boas práticas de implementação

# 🔍 Test Patterns

Estudo dos principais padrões utilizados para isolamento de dependências em testes.

### Conteúdo

- Fundamentos dos Test Patterns
- Test Double
- Stub
- Spy
- Mock
- Fake

Aprender quando utilizar cada tipo de objeto de teste e entender seus impactos na confiabilidade e manutenção da suíte de testes.

# ♻️ Refactoring

Estudo contínuo sobre melhoria de código sem alteração de comportamento.

### Conteúdo

- Fundamentos do Refactoring
- Code Smells
- Técnicas de Refactoring
- Extração de Métodos
- Extração de Classes
- Simplificação de Condicionais
- Redução de Acoplamento
- Melhoria de Legibilidade
- Uso de Inteligência Artificial para manutenção da qualidade do código

### Objetivo

Desenvolver a capacidade de identificar problemas estruturais e evoluir bases de código de forma segura.

---

# 🧹 Clean Architecture

Estudo dos conceitos propostos por Robert C. Martin (Uncle Bob) para construção de sistemas independentes de frameworks, bancos de dados e tecnologias externas.

### Conteúdo

- Fundamentos de Clean Architecture
- Entities
- Use Cases
- Interface Adapters
- Frameworks and Drivers
- Estrutura de Pastas
- Regra das Dependências
- Boundary Interfaces
- Separação entre Domínio e Infraestrutura

### Objetivo

Aprender a criar aplicações altamente desacopladas, testáveis e preparadas para mudanças tecnológicas.
